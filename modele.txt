#  LISTA DE MODELE MONITORIZATE  (editeaza liber)
# ============================================================
#
#  Un model pe rand. Doua forme posibile:
#
#    Canon 600D
#    Canon 600D = 600d, t3i
#
#  - Textul din STANGA lui "=" e folosit ca termen de cautare pe ambele
#    site-uri. Tine-l scurt: marca + model (ex. "Canon 600D", nu
#    "Canon EOS 600D Kit 18-55").
#  - Dupa "=" (optional) pui variantele de scriere ale modelului, separate
#    prin virgula. Scriptul pastreaza doar anunturile al caror titlu
#    contine una dintre ele. Spatiile si cratimele nu conteaza
#    ("x-t3" prinde si "XT3" si "X T3").
#    Daca nu pui "=", se foloseste numele fara marca (ex. "600d").
#  - Un "#" la inceputul randului dezactiveaza modelul (e ignorat).
#
#  Modelele "Mark II/III" sunt separate automat: "a7 iii" NU prinde
#  "a7 ii" sau "a7r iii", iar "z6" NU prinde "z6 ii".
#
#  Toate au pret uzual la mana a doua sub ~1000 EUR (sept 2026).
# ============================================================
